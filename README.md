# 同词相遇 · Word Meet

手机优先的双人同屏试玩游戏。两人轮流使用一部手机：各写一个词，同时揭晓，再根据上一轮的两个词联想，直到同词。

当前为纯静态试玩版，无需第三方 CDN、字体或接口。答案和进度保存在本机浏览器。两台设备异地自动同步尚未接入。

## 发布到 GitHub Pages

仓库 Settings → Pages → Build and deployment → Source 选择 Deploy from a branch → Branch 选择 main 和 / (root) → Save。

构建成功后访问 https://yejidog.github.io/word_meet/ 。在 Pages 配置并部署成功前，该地址不可用。

国内访问效果以双方实际网络测试为准。
